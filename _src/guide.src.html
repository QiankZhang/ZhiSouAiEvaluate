00 — Before you start

开始之前

智搜评估系统用来衡量「智搜」策略调整后的效果。系统提供两条评估主线—— AI 评估中心（裁判员模型按既定标准逐条打分 + 人工复核）与 人工评估中心（纯人工逐条标注），两者都以自动汇总的评估报告收尾。

登录

打开系统即为登录页。账号为姓名的小写拼音，初始密码 为 12345678，登录后请尽快在账号菜单「修改密码」中更新。 所有数据归属于唯一组织智搜产品； 未加入组织的账号无法查看任何数据集、基准与任务，需由组织成员在「成员管理」中邀请（详见 07 账号与组织）。

导航结构

左侧边栏分三块，另在左下角常驻使用指南入口（即本手册）：

入口内容

AI 评估中心点标题进入评估任务列表；其下三个子项：数据集 · 评估基准 · 评估报告模板
人工评估中心纯人工标注工作台，与「AI 评估中心」平级

两种评估机制（贯穿全系统）

系统底层只有两种打分机制，它决定数据集的必需列、基准的配置项、报告的呈现方式。 机制的显示名称可以自定义（如把「多维度」改叫「语义相似度评估」），但底层仍是这两种之一。

多维度　MULTI_DIM

按若干维度加权打分，每维 1–5 分。

  • 必需列：query、content
  • 基准里配「维度 + 权重」，权重合计需 = 100%
  • 默认维度：相关性 / 全面性 / 准确性 / 可读性 / 时效性，各 20%
  • 报告给出各维度均值、低分占比、总分分布

GSB 对比　GSB

实验对象 vs 基线对象，逐条判 Good / Same / Bad。

  • 必需列：query、content、baseline
  • 基准里配「判定规则 + 裁决维度」
  • 报告给出 G∶S∶B、胜率、净胜率 =（G−B）/（G+S+B）

协同分工

人工定标准——由你设计数据集、评估基准与报告模板；AI 做执行——裁判员模型逐条打分、依模板撰写报告；人工兜置信——你在任务详情里逐条复核，通过或调整后报告才最终定稿。人工评估中心则是把「打分」这一步也交回人工。

01 — Datasets

数据集管理

数据集是一批待评样本的集合。进入 AI 评估中心 › 数据集 查看全部数据集， 支持按名称 / ID 搜索，按来源、创建人、创建时间筛选。 「数据源连接」标注 待开发，暂不可用。

创建数据集

点击右上角「创建数据集」，在弹窗中填写并上传文件。

  1. 填写数据集名称（必填，≤ 50 字）与数据集描述（选填，≤ 200 字）。

  2. 选择评估方式。它决定必需列——多维度机制需 query / content；GSB 机制额外需 baseline。

    下拉底部的「+ 新增评估方式…」可自定义一个显示名称，并指定它属于「多维度机制」还是「GSB 机制」。

  3. 点「下载标准模板」拿到对应机制的 CSV 表头，或点「查看数据集样例」直接在弹窗里预览字段格式。

  4. 把整理好的文件拖入上传区，或点击选择。支持 CSV / JSON / JSONL / XLSX，单文件 ≤ 50 MB。

  5. 点「保存」。若某些行缺少必需列，弹窗会按「第 N 行：原因」逐条列出错误，修正后重新上传即可。

字段说明约束
数据集名称 必填列表与选择器中显示的名称≤ 50 字
数据集描述用途与范围说明≤ 200 字
评估方式 必填决定必需列与后续可匹配的基准多维度机制 / GSB 机制
数据文件 必填样本内容CSV / JSON / JSONL / XLSX，≤ 50 MB
query用户查询两种机制都必需
content智搜回答（实验对象）两种机制都必需
baseline基线回答（对照对象）仅 GSB 机制必需

查看与维护

点数据集名称进入详情页：上方是基本信息（条数、字数、创建人、时间）与 被引用任务列表，下方是样本预览（仅展示前若干条，GSB 会多出「基线内容」列）。 列表页每行操作区可下载原始文件或删除。

删除限制

只要数据集正被任意评估任务引用，删除按钮即不可用。需先删除或改绑相关任务，才能删除该数据集。

02 — Benchmarks

评估基准管理

评估基准 = 一套可复用的打分标准。进入 AI 评估中心 › 评估基准， 可按评估类型（提示词类型 / 技能 Skill）、评估方式（多维度 / GSB）、创建人筛选。 每个基准带版本号与状态（已验证 / 未验证），以及被任务引用的使用次数。

创建评估基准（两步向导）

第一步 · 基础信息

  1. 填写基准名称（必填，≤ 50 字）与基准描述（选填，≤ 200 字）。

  2. 选择评估类型：

    提示词类型 用提示词编辑器 + 变量面板表达标准；技能 Skill 使用符合 Anthropic Agent Skills 规范的技能包。

  3. 选择评估方式（多维度机制 / GSB 机制，同样支持「+ 新增评估方式」自定义显示名）。点「下一步」。

第二步 · 指令配置（内容随「评估类型 × 评估方式」变化）

  1. 提示词类型：在提示词编辑框写评测指令，可从变量面板插入 {query} {待评内容} {维度} {评分标准}（GSB 另有 {基线内容}）。 维度、权重、评分标准、判定规则都直接写在提示词里。下方标准输出格式展示裁判员模型应返回的 JSON 结构。

  2. 技能 Skill：选技能来源——「内置技能」（multi-dimension-evaluation / gsb-evaluation，随平台维护）， 或「上传技能包」（.zip 根目录含 SKILL.md，或单个 SKILL.md，≤ 10 MB）。上传后系统解析并展示技能名称、版本、许可证与说明。

  3. 按需勾选「输出结果附带置信度字段」。

  4. 多维度机制：在维度与权重区增删维度、填写权重，底部实时显示合计，必须等于 100%才能保存。

    GSB 机制：填写判定规则（≤ 200 字）与裁决维度（如 overall / relevance）；数据集里的 baseline 即基线对象。

  5. 点「保存」。

配置项提示词类型技能 Skill
标准表达提示词编辑框 + 变量面板内置技能，或上传 SKILL.md / .zip
多维度机制维度与权重区，权重合计 = 100%
GSB 机制判定规则 + 裁决维度；baseline 作基线
置信度勾选「输出结果附带置信度字段」

查看与维护

点基准名称进入详情页，按配置类型分别展示维度与权重 / GSB 判定规则 / 技能 Skill 详情 / 提示词全文，以及被引用任务。 行内 / 详情页均可编辑、复制（生成新基准便于微调）、删除。

删除限制

使用次数 > 0（正被任务引用）的基准无法删除。可先复制一份作为新版本迭代，旧版本留给历史任务。

03 — Report templates

评估报告模板

评估报告模板决定任务完成时那份 Markdown 报告怎么写——由 AI 依据模板对评测/标注结果做汇总撰写。 进入 AI 评估中心 › 评估报告模板，可按名称 / ID 搜索，按类型筛选。 首次使用系统会内置一份 技能 Skill 型「默认评估报告」（evaluation-report），可直接用、可复制改、也可删除。

两种模板类型

技能 Skill　SKILL

  • 用内置 evaluation-report，或上传自定义技能包
  • 技能的 instructions 就是报告写作规范
  • 适合有成套报告规范、要跨任务统一风格的场景

提示词类型　PROMPT

  • 一段报告提示词 + 一份章节清单
  • 提示词里的 {章节} 会被替换为勾选的章节
  • 默认章节：整体结论 / GSB 专项评估 / 分维度问题分析 / 典型错误 case 分析 / 改进建议

创建报告模板（两步向导）

  1. 基础信息：填写模板名称（必填，≤ 50 字）、模板描述（选填，≤ 200 字），选择模板类型（技能 Skill / 提示词类型）。点「下一步」。

  2. 报告配置：

    技能 Skill — 选技能来源：内置技能下拉，或上传 .zip（根目录含 SKILL.md）/ SKILL.md（≤ 10 MB）；解析后展示技能名称、版本与指令全文。

    提示词类型 — 在提示词编辑框写作规范（可插入 {章节} 变量），并在下方勾选 / 增删报告章节。「GSB 专项评估」这一章仅当任务为 GSB 对比时才会写入报告。

  3. 点「保存」。

与任务的关系

创建 AI 评估任务或人工标注任务时都会选一个报告模板。任务完成后按该模板生成报告。不选模板（AI 任务里选「不生成智能报告」）则回退到系统内置的确定性五段式报告。使用次数 > 0 的模板不可删除。

04 — Evaluation tasks

AI 评估任务

点侧边栏「AI 评估中心」标题即进入评估任务列表。列表展示每个任务的 状态、任务类型、评估方式、所用基准、样本量与进度，可按任务名 / ID / 创建人搜索， 按状态、评估方式、任务类型、裁判员模型、创建人筛选。

状态含义可用操作
未开始已创建、尚未执行执行评测 · 编辑 · 复制 · 删除
执行中裁判员模型正在逐条打分停止
已完成打分完成，待 / 已复核人工审核（未复核完）/ 查看报告（已复核）· 复制 · 下载测试集 · 删除
已停止执行中被手动停止执行评测（继续）· 编辑 · 复制 · 删除
执行失败执行异常终止重试 · 编辑 · 查看失败原因

第 1 步 · 创建任务

  1. 点右上角「创建评测任务」。填写任务名称（必填，≤ 50 字）、任务描述（选填，≤ 50 字）。

  2. 填任务类型（自由文本，输入过的会进联想；默认建议「通用评估」「博文分析」）——仅用于数据概览的类型统计。

  3. 选评估基准（必填）。评估方式由基准隐式决定，并据此过滤下方可选数据集。

  4. 选评测数据（必填，只列出与基准同机制的数据集）。也可点「创建新数据集」就地新建。

  5. 选AI 裁判员模型（必填）。默认 deepseek-v4-flash（DeepSeek V4 Flash · 推荐）；下拉里标「走模拟引擎」的模型不会真实调用。

  6. 选评估报告模板（可选）。不选则任务完成时用内置固定模板出报告；也可点「新建报告模板」就地新建。

  7. 弹窗底部给出预估：字数、token、耗时、成本。确认后点「创建任务」——创建后自动开始执行。

第 2 步 · 执行评测

未开始 / 已停止的任务可在列表或详情点「执行评测」，任务转入执行中， 详情页显示实时进度（已完成 / 总样本）。需要时可「停止」；执行失败时点「重试」， 并在详情页顶部查看失败原因。

进度四段

任务详情顶部的步骤条对应：数据准备 → AI评测 → 人工复核 → 报告。统计行显示样本量、预估字数、预估 / 实际成本、预估耗时、评测引擎（真实调用 / 模拟，或「部分降级」）与复核进度。

第 3 步 · 人工复核

打分完成后，在任务详情的「评测结果」表逐条复核。每行给出样本 Query、评分（多维度为总分及各维分；GSB 为 Good/Same/Bad 及双方总分）与理由。

  1. 认可 AI 判分——点该行「通过」。

  2. 需要修正——点「调整」：多维度可改各维 1–5 分（总分自动按权重重算）；GSB 可改判定结果；并填写复核说明。保存后该行标记已调整。

  3. 批量处理——点表头「全部通过（N）」一次通过所有待复核行。

  4. 所有行复核完毕后，复核状态转为已复核，系统自动跳转到评估报告页。

第 4 步 · 阅读评估报告

报告正文由所选报告模板驱动（章节与措辞随模板变化），页面顶部先是指标卡与 GSB 占比条 / 多维度概览。若人工复核尚未完成，报告顶部会提示「初步统计，复核结果确认后同步更新」。

默认章节多维度GSB
整体结论最弱 / 最强维度、全链路判断整体强弱于基线，G∶S∶B 速览
专项分析分维度问题分析：各维均值、低分占比、总分分布GSB 专项评估：Good/Same/Bad、胜率、净胜率
典型错误 case按错误类型聚合 + 2~3 个典型 case 详评（原始 Query、问题定位、原文问题片段）
改进建议对应共性短板的可落地建议

页面右上角可复制 Markdown、下载 Markdown、下载 Excel（原始打分表）。 报告下方还有逐样本明细表与可展开的 Markdown 源码。

复用与追溯

已完成任务可「复制任务」快速发起回归；「下载测试集」导出逐样本打分明细（CSV）。报告页头部始终显示所用基准、数据集、裁判员模型与引擎，便于追溯。

05 — Manual evaluation

人工评估中心

人工评估中心是一个纯人工标注工作台：上传数据后由人逐条判读，标注满自动汇总， 再由你主动触发 AI 依据标注结果撰写报告。适合 AI 裁判员难以胜任、或需要人来定调的评测。

01
上传数据
选标注类型 + 传文件 + 定维度 + 选报告模板
→
02
逐条标注
在工作台里一条条判读 / 打分
→
03
自动汇总
标注满后即时汇总胜率 / 均值 / 低分
→
04
AI 报告
主动点「AI 生成评估报告」

三种标注类型

类型数据字段标注方式
GSB 标注query / content / baseline左右分栏对比，判 G（实验更好）/ S（持平）/ B（实验更差）
多维度评估标注query / content单栏内容，各维度 1–5 分，自动加权总分（可手动指定）
多轮对话标注session_id / turn / role / content按 session 聚合成对话，整段一个多维打分

创建标注任务

  1. 点「创建标注任务」，填任务名称（必填，≤ 50 字）与任务描述（选填，≤ 200 字）。

  2. 选标注类型（GSB / 多维度 / 多轮对话，创建后不可修改）。GSB 可另设左右布局（决定工作台里基线与实验哪边在左）。

  3. 点「下载 XX 模板」拿到对应字段的模板，整理数据后拖入上传区。GSB / 多维度支持 CSV / XLSX；多轮对话支持 JSONL / JSON / CSV（按 session_id 分组）。

  4. 多维度 / 多轮对话需配评分维度（默认五维各 20%，可增删改，权重合计需为 100%）。

  5. 选评估报告模板（必填，标注完成后由 AI 依据此模板撰写报告）与报告生成模型。

  6. 点「创建并开始标注」，直接进入标注工作台。

标注工作台

左侧是单元列表（可按「全部 / 未标注 / 已标注 / 已跳过」过滤，圆点表示完成状态）， 右侧是当前单元的判读区。下方每条都可填备注，或点「跳过 / 无法判断」。 GSB 类型判定后会自动跳到下一条未标注项。

类型判读区
GSB顶部 query + 左右两栏（基线 / 实验）+ 「G·实验更好 / S·持平 / B·实验更差」三按钮
多维度顶部 query + 单栏内容 + 各维度 1–5 分选择条 + 自动总分（可勾「手动指定总分」）
多轮对话按 session 聚合的对话气泡（左＝用户、右＝模型）+ 整段一个多维打分

汇总与 AI 报告

点右上角「查看汇总」进入汇总页：指标卡（样本总量 / 已标注 / 已跳过 / 完成率）、 分数汇总（GSB 给 G∶S∶B 条与胜率 / 净胜率；多维度给平均总分、各维均值条与分布）、 以及被判 B / 低分样本清单。

  1. 标注全部完成后，点右上角「AI 生成评估报告」，由 AI 依据标注结果 + 所选报告模板撰写；生成中会自动轮询刷新。未完成时该按钮不可用，只能看初步汇总。

  2. 报告就绪后可「下载报告」（.md）。任意时刻可「导出明细」（逐条标注结果 CSV）。

06 — Overview

数据概览

侧边栏「数据概览」是全局监控视图，也是登录后的默认落地页。 右上角切换时间范围：今日 近7天 近30天 自定义（选自定义后需指定起止日期，指标才会加载）。

07 — Account & org

账号与组织

系统只有一个组织智搜产品，所有数据集、基准、模板、任务都归它所有—— 换句话说，在不在组织里决定你能不能看到这些数据。

顶栏账号菜单

点顶栏右侧的姓名，展开菜单：

菜单项作用
修改密码原密码 + 新密码（8–64 位）。改后其它设备需重新登录
成员管理进入成员列表（仅组织内成员可见）
退出组织退出后成为孤立账号，看不到任何数据，需被重新邀请
退出登录结束当前会话

成员管理

组织内任意成员都可以管理成员：

  1. 添加成员——填姓名 + 账号（2–32 位小写字母 / 数字 / 下划线，建议用姓名拼音），初始密码 12345678。若该账号已存在且为孤立账号，则直接邀请其加入（可不填姓名）。

  2. 重置密码——把某成员的密码重置回 12345678。

  3. 移出组织——把他人移出（不能移自己）；被移出者变为孤立账号。

孤立账号

没有组织的账号登录后，侧边栏各功能禁用，页面提示联系组织成员邀请。把账号加回组织后即恢复。
